# Hello OSS Project

## 1. Giới thiệu

Hello OSS Project là dự án mã nguồn mở đơn giản được viết bằng Python. Chương trình in ra màn hình dòng chữ "Hello Open Source".

## 2. Mục tiêu

- Làm quen với quy trình phát triển phần mềm mã nguồn mở.
- Thực hành quản lý mã nguồn bằng Git và GitHub.
- Học cách viết tài liệu README, CONTRIBUTING và sử dụng giấy phép OSS.

## 3. Yêu cầu

- Máy tính đã cài đặt Python 3.
- Đã cài đặt Git nếu muốn clone và quản lý mã nguồn bằng Git.

## 4. Cài đặt

Clone repository về máy:

```bash
git clone https://github.com/USERNAME/hello-oss-project.git
cd hello-oss-project
```

Thay `USERNAME` bằng tên tài khoản GitHub của chủ repository.

## 5. Cách chạy chương trình

```bash
python hello.py
```

Kết quả:

```text
Hello Open Source
```

## 6. Đóng góp

Mọi người có thể báo lỗi hoặc đề xuất cải tiến theo hướng dẫn trong file CONTRIBUTING.md.
